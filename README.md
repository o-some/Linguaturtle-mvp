# LinguaTurtle MVP

Ein kostenloser, mobil optimierter Sprachlern-Prototyp für Kinder: Deutsch ↔ Spanisch.

## Funktionen

- ohne Anmeldung
- Browser-Sprachausgabe
- kindgerechte Tierübung
- lokale Fortschrittsspeicherung
- installierbare PWA
- GitHub-Pages-kompatibel

## Lokal starten

```bash
python3 -m http.server 8080
```

Danach `http://localhost:8080` öffnen.

## Veröffentlichung

Das Repository enthält einen GitHub-Pages-Workflow unter `.github/workflows/pages.yml`. Jeder Push auf `main` veröffentlicht den aktuellen Stand automatisch.
